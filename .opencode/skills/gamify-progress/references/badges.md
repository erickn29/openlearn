# Бейджи

| Бейдж | Условие |
| --- | --- |
| `first_packet` 🎓 | Пройден урок 1 |
| `signal_acquired` 📡 | Пройдена диагностика |
| `three_way_handshake` 🔌 | Пройдено 10 уроков (или все, если предмет короче) |
| `flawless` 💯 | Любой результат 9/9 |
| `subnet_slayer` 🧮 | 9/9 на уроке, в названии которого есть подсеть/маска/CIDR |
| `comeback_kid` 🧗 | Урок сдан после попытки с оценкой ≤3 |
| `streak_3` 🔥 | 3 учебных дня подряд |
| `streak_7` 🌋 | 7 учебных дней подряд |
| `rfc_reader` 📜 | Ученик сослался на RFC или документацию (`--sources`) |
| `boss_defeated` 🏆 | Пройден финальный урок секции — чек-поинт «всё вместе» |
| `night_owl` 🦉 | Урок засчитан между 00:00 и 05:00 по местному времени (скрытый) |
| `speedrun` ⚡ | 5 уроков за один день (или все, если предмет короче; скрытый) |

Скрытые бейджи не показываются на дашборде до получения. Никогда не анонсируй их заранее.

Пороги `three_way_handshake` и `speedrun` считаются как `min(порог, total_lessons)`: уроки атомарные, и в предмете из 8 уроков порог «10 уроков» был бы недостижим.
