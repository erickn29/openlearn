# Требования рынка

Скилл отвечает на вопрос «что ждут от человека на этой роли прямо сейчас» и превращает ответ в файл, на который опирается `plan.md`.

Данные берутся из публичного поиска hh.ru. API вакансий (`api.hh.ru/vacancies`) закрыт без OAuth-токена и отдаёт 403 — это не ошибка сети. Работает HTML-выдача: весь результат страницы лежит в `<template id="HH-Lux-InitialState">`. Подробности разметки — в `references/hh-web.md`.

## Кто что пишет

| Файл | Владелец | Правило |
| --- | --- | --- |
| `market.json` | `scripts/market.mjs` | руками не править |
| `market.md` | `scripts/market.mjs` | руками не править |

Учитель читает `market.md`, но не запускает скрипт: сбор — работа оркестратора.

## Шаги

1. Спроси ученика, на какую роль он целится, где ищет работу и в каком формате (офис, гибрид, удалёнка).
2. Подбери id роли. Справочник открыт без токена:

```sh
node .opencode/skills/market-research/scripts/market.mjs roles --text "аналитик данных"
```

Покажи 2–3 совпадения и попроси подтвердить.

3. Собери снапшот:

```sh
node .opencode/skills/market-research/scripts/market.mjs collect \
  --subject subjects/<slug> \
  --role 156 --area 1 --format any \
  --limit 200 --details 50
```

4. Отрисуй отчёт:

```sh
node .opencode/skills/market-research/scripts/market.mjs render --subject subjects/<slug>
```

5. Передай `market.md` учителю вместе с задачей на `plan.md`.

## Параметры сбора

| Флаг | По умолчанию | Смысл |
| --- | --- | --- |
| `--role <id>` | — | роль из справочника hh; нужен один из `--role` / `--text` |
| `--text <строка>` | — | свободный запрос вместо роли |
| `--area <id>` | `1` | регион hh; `1` — Москва, `113` — вся Россия |
| `--format` | `any` | `any` / `remote` / `hybrid` / `onsite` |
| `--limit <n>` | `200` | сколько вакансий взять из поиска, максимум 2000 |
| `--details <n>` | `50` | сколько карточек дотянуть, максимум 200; `0` — только поиск |
| `--pause-min` / `--pause-max` | `800` / `1500` | пауза между запросами, мс |
| `--timeout <мс>` | `20000` | таймаут одного запроса |
| `--max-seconds <с>` | `300` | бюджет на весь сбор; `0` — без лимита |
| `--retries <n>` | `2` | повторы на 429/5xx/таймаут |
| `--fresh-days <n>` | `14` | свежий снапшот с теми же параметрами не пересобирается |
| `--force` | — | пересобрать несмотря на свежесть |

Бюджет считается грубо: `--limit 200 --details 50` — это примерно 3 запроса поиска плюс 50 карточек, при паузе 800–1500 мс около 60–90 секунд.

## Коды выхода

| Код | Значение | Что делать |
| --- | --- | --- |
| `0` | ок | читать `market.md` |
| `1` | параметры | поправить флаги |
| `2` | сеть, 403, капча, VPN | проверить российский IP, повторить позже |
| `3` | **разметка hh изменилась** | чинить парсер, отчёт не готов |

Код `3` — самый важный. Он означает, что hh поменял HTML и скрипт не смог разобрать страницу. Пустой отчёт в такой ситуации хуже ошибки: он молча превращается в «на рынке ничего не требуется».

Починка: переснять фикстуры и прогнать тесты.

```sh
node .opencode/skills/market-research/scripts/record-fixtures.mjs --role 156 --area 1
node --test test/market.test.mjs
```

## Как читать отчёт

`market.md` начинается с рамки выборки: регион, формат, сколько вакансий собрано, дата. Любая цифра ниже читается только с этой поправкой.

- **Доля навыка** считается от вакансий с заполненными навыками, а не от всех собранных. Иначе «SQL в 40%» вместо реальных 70%.
- **Навыки из текста.** Если работодатель не заполнил `keySkills`, технологии ищутся в сниппете требований и в теле вакансии по словарю алиасов. Такие находки отмечаются отдельно: их доля в `coverage`.
- **Зарплата** считается по середине вилки, только в рублях. Вакансии без зарплаты в медиану не входят, поэтому медиана описывает тех, кто зарплату указал.
- **Опыт и формат** — по полям `workExperience` и `workFormats`, без домыслов.

## Правило для учителя

Навык с долей **30% и выше** либо закрыт уроком в `plan.md`, либо явно отнесён к разделу «сознательно вне программы» с причиной. Это делает план проверяемым: видно, что программа соответствует вакансиям, а не составлена по вкусу.

## Ограничения, которые нужно называть вслух

- Срез не равен рынку: одна роль, один регион, один момент времени.
- Потолок выдачи — 2000 позиций (`page` больше 19 отдаёт 404). Для широких ролей режь по регионам или формату.
- `keySkills` заполнены не у всех — в отчёте это видно по `coverage`.
- hh может включить капчу при жадном сборе: не уменьшай паузы ниже `800` мс без причины.
- Данные hh нельзя передавать третьим лицам (соглашение dev.hh.ru, п. 4.6). Снапшоты лежат локально, наружу отдаём только агрегаты.
