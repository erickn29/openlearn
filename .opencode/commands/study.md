Пользователь хочет изучать: $ARGUMENTS

1. Определи, что просит ученик:
   - тема («компьютерные сети», «регулярные выражения») → один предмет `subjects/<slug>/`;
   - профессия («python backend», «data analyst») → трек `tracks/<slug>/` из нескольких секций.
   Если непонятно — спроси прямо: «один курс по теме или программа из курсов под профессию?».
2. Для предмета: если `subjects/<slug>/` существует — прочитай `plan.md` и `progress.json` и продолжи с текущего урока, ничего не пересоздавай.
3. Для трека: если `tracks/<slug>/track.json` существует — отрисуй `track render` и продолжи с первой незакрытой секции.
4. Иначе выясни роль, регион поиска и формат работы (офис, гибрид, удалёнка).
5. Собери требования рынка по skill `market-research`: `roles` → подтверждение роли → `collect` → `render`. Для трека снапшот собирается один раз на профессию.
6. Создай структуру по skill `subject-setup`: для темы — один предмет, для профессии — секции + `track init`.
7. Вызови `teacher` для плана и диагностики, передав `market.md`.
8. Покажи план, число уроков и примерное время в часах. Не начинай урок 1 до ответов на диагностику.
